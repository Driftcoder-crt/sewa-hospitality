## FAQ-style notes

- **Why Laravel 13 + Livewire 4 + Tailwind 4.3?** First-party AI SDK built in, modern, stable, shared-hosting compatible, no primitive or problematic dependencies (Filament excluded by policy).
- **Why Ably over Pusher?** 6M messages/month free vs Pusher's 200K/day hard daily cap that can 403 mid-day; protocol Laravel Echo supports natively; migration to Reverb later is trivial.
- **Why is the blog on /blog/ and not a subdomain?** SEO equity concentrates on the root domain; a subdomain would split it. WordPress-style dated URLs preserved for the same reason.
- **Where do I start reading?** Executive summary → Formula reference site map → stack doc → module system → build roadmap.
