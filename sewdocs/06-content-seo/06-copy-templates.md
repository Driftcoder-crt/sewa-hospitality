# 06 — Copy Templates

**Ready-to-fill templates for every page type — structure, tone, and placeholders — so copy can be drafted fast, in brand voice, with SEO slots pre-defined. (Patterns and structures only; original copy is copyrighted — Sewa writes its own.)**

---

## How to use these
Each template: block order, purpose per block, word-count guidance, SEO slots (title/description/H1), and the proof/claim discipline (every number needs a source + "as of"). Fill-in slots marked `{…}`. Voice: [../01-platform-vision/02-brand-sewa-hospitality.md](../01-platform-vision/02-brand-sewa-hospitality.md) §3.

---

## 1. Homepage
```
SEO title: Corporate Relocation & Mobility Services in India | Sewa Hospitality
H1: Relocation and mobility services for India — handled with care
BLOCKS
  hero: headline = H1 · sub = 1 line promise (2-hour response, 25-city network {as-of})
        · CTAs [Talk to a consultant] [Explore services]
  who_we_are (3 short paras): what Sewa does · who trusts us (client segments, honest counts)
        · what makes it different (care + systems: portal, named consultants)
  stats: 3 honest counters + "as of" lines
  solutions: 2 family cards (Employee / Business Mobility) — 1 line each + link
  how_we_work: 4 steps (Consult → Plan → Move → Settle) — 15 words each
  testimonials: 4 review cards (source badges)
  cta_band: "Not sure which solution fits?" + [Get a move plan]
```

## 2. Service hub leaf page (`/services/…`)
```
SEO title: {Service} in India | Sewa Hospitality
H1: {Service} in India
  hero (service image, focal) + intro (80–120 words: what it is, who it's for, cities)
  scope accordions (5–7 items): each = {Capability} · 40–60 words · concrete deliverable
  city coverage strip: {cities where offered} — linked
  consultant card: named person, role, languages
  reviews for this service: 2–3 cards
  faq: 4–6 real questions
  cta_band: service-specific ("Request {x}")
```

## 3. Immigration leaf pages (inbound/outbound/ancillary)
```
Add after intro: compliance timeline graphic-block (what's due when, stages)
Add: document checklist block (interactive, printable)
Keep: fee-transparency table (official fees vs Sewa service fee — honesty play)
FAQ heavier here (6–10) — FRRO/OCI/PAN questions are the AEO goldmine
```

## 4. City page (`/cities/{slug}`)
```
SEO title: Relocating to {City}: Housing, Schools & FRRO Guide | Sewa
H1: Relocating to {City}
  answer-first intro: 2–4 sentences — who the city suits, cost level, Sewa coverage
  snapshot stats band (rent band, top areas, FRRO office — all dated)
  housing inventory cards (tiers, from-rates, verified badges)
  neighborhoods: 4–6 cards (who it suits, rent band, commute note)
  family block: schools (2–4 with curricula), healthcare (2–3)
  transport/fleet block
  compliance block: FRRO office address/process specifics for THIS city
  international community block (Japanese/Korean/other communities, groceries, interpreters)
  testimonials: this city
  faq: 6–10 harvested questions
  cta_band: "Moving to {City}? Talk to a {City} consultant"
```

## 5. Housing unit detail (`/housing/{unit}`)
```
H1: {Name}, {Locality}, {City}
  gallery (8–12 photos) · key facts band (tier, bedrooms, from-rate, availability)
  what's included checklist · amenities grid
  neighborhood 2-liner · verified badge + "what we check" link
  availability enquiry (dates + city + unit pre-filled)
```

## 6. Blog post templates
```
EXPLAINER (e.g. FRRO registration):
  SEO title: {Question-style or noun phrase} | Sewa Hospitality
  answer-first lead (2–4 sentences) → who needs it → steps (ordered list)
  → documents checklist table → timeline/costs → common mistakes
  → FAQ (3–5) → CTA (related service)
  900–1,400 words · named author with credentials

GUIDE (city/market):
  verdict first → sections by cluster (housing/schools/transport)
  → data table (dated) → practical checklists → CTA

THOUGHT LEADERSHIP:
  POV opener (1 para) → argument (3 H2s) → implications for mobility teams
  → what Sewa does differently (1 para, no hard sell) → author = leadership

NEWS:
  what happened (2 sentences) → who it affects → what to do now (dated)
  → Sewa's operational note if relevant · 300–500 words
```

## 7. About / team / leadership
```
About: H1 "This is Sewa" — mission (100 words) → how we work (systems behind care)
  → values as real content (4–6 named values, each 2 lines — NOT a graphic)
  → leadership grid (clickable profiles) → CSR teaser → stats (dated)
Leadership profile: name · role · 60–90 word bio (real, human detail)
  · credentials · languages · LinkedIn · "works with {segments}"
```

## 8. Careers
```
Careers hub: H1 "Careers at Sewa" — why work here (3 real reasons, no clichés)
  → open roles list (dept/city chips) → life at Sewa (gallery + 150 honest words)
  → how hiring works (3 steps) → referral/contact email
Job page: role · commitment to candidates (response-time promise)
  → responsibilities (5–7 bullets) → requirements (5–7) → what you get
  → apply form + expectations ("we reply within {x} working days")
```

## 9. Contact / offices
```
Contact: H1 "Talk to Sewa" — response SLA statement (2 business hours {policy})
  → form (progressive disclosure) → offices tabs (address, map facade, phone/email)
  → a note on languages ("write in English, Hindi, 日本語, 한국어, العربية, Türkçe")
```

## 10. Legal & transparency pages
```
Privacy/Cookies: plain-language summary first (what we collect, why, rights, contact)
  → full policy sections below · version + date footer
Pricing approach (transparency page): how quotes work, what drives cost,
  rate-range examples with as-of dates, what's always included (no hidden fees claim = show it)
How we work: the 4-step journey + SLAs + who your named consultants are
```

## 11. Review request & transactional emails
```
review.request: subject "How was your move to {City}?" · body: 60 words thanks
  + Google link (one CTA) + private-feedback fallback link · one follow-up max (7 days)
application.ack: thanks → what happens next + timeline → data note (retention + contact)
lead.ack: received → SLA promise → what to have ready (docs/needs) → reply-any-language note
```

## 12. Microcopy bank (UI strings)
```
Buttons: Get a move plan · Check availability · Talk to a consultant · Book a walkthrough
Form labels: Full name · Email · Phone (with country code) · How can we help? · Service (if known)
Errors (kind + specific): "Enter an email address like name@company.com"
Empty states: "No results — try a nearby city" + [Suggest a topic]
Footers/consent: cookie note (plain), language names (not flags)
```

## 13. Writing rules recap (applies to every template)
- Answer-first, one H1, H2/H3 ladder; ≤ 4-line paragraphs.
- Numbers: sourced + "as of" + range-style honesty.
- Named humans wherever possible (consultants, authors, reviewers).
- Every page: one clear next action; CTAs name the outcome.
- Locale registers ([04-multilingual-content.md](04-multilingual-content.md) §3) applied at translation — never machine-raw published.
