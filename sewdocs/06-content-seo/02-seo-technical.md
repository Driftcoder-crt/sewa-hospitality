# 02 — Technical SEO Specification

**Every technical SEO mechanism, specified per page type — fixing every defect found in the reference (no sitemap, no robots, double H1s, empty lang, fake hreflang, placeholder metas, rating schema without reviews) and adding what it never had.**

---

## 1. Head stack (per page type)

### 1.1 Core tags (all pages)
```
<!DOCTYPE html><html lang="{locale}" dir="{ltr|rtl}">
<title>…</title>                       <!-- template per type below, ≤ 60 chars -->
<meta name="description" content="…"> <!-- unique, required at publish, ≤ 160 chars -->
<link rel="canonical" href="…">       <!-- absolute, self-referential, locale-specific -->
<meta name="robots" content="{index,follow[,max-image-preview:large]}"> <!-- noindex = explicit admin action only -->
```
**No legacy meta spam** (the reference ships DC.*, revisit-after, distribution, dcterms.* — all dropped).

### 1.2 Title/description templates
| Page type | Title | Description |
|---|---|---|
| Home | `Corporate Relocation & Mobility Services in India | Sewa Hospitality` | brand + cities + differentiator (care + SLA) |
| Service hub | `{Service} in India | Sewa Hospitality` | scope + city coverage + proof |
| Service leaf | `{Sub-Service} Services {City-ish} | Sewa Hospitality` | scope + CTA promise |
| City page | `Relocating to {City}: Housing, Schools, FRRO Guide | Sewa` | city promise + services |
| Housing | `Serviced Apartments & Corporate Housing in {City} | Sewa` | inventory + verified standard |
| Blog post | `{Post Title} \| Sewa Hospitality` | answer-first 150 chars |
| Category | `{Category} Guides | Sewa Hospitality` | archive intro summary |
| Portal/admin/API | `noindex` by middleware | — |

Template enforcement is in the CMS/blog publish gates ([../04-modules/01-cms.md](../04-modules/01-cms.md) §5) — empty/placeholder metas **cannot publish** (the reference's "metatitle" bug becomes structurally impossible).

### 1.3 Open Graph / Twitter (all public pages)
```
og:locale / og:type / og:title / og:description / og:url / og:site_name
og:image (1200×630 conversion, absolute media.sewa URL) + width/height/alt
article:published_time / article:modified_time / article:author / article:tag (posts)
twitter:card summary_large_image (+ title/description/image)
```
(One generator service — the reference hand-maintains these and loses on news pages.)

## 2. Internationalization
- Locale paths (`/ja/…`) + `hreflang` alternates per URL: every published locale + `x-default` → en ([../04-modules/11-multilingual.md](../04-modules/11-multilingual.md) §3).
- Correct `lang`/`dir` on every page (never empty `lang=""` — reference defect).
- `Content-Language` consistency; localized URLs in sitemap with alternates; one sitemap index covering all locales.

## 3. Sitemap & robots (the reference has neither)

### sitemap_index.xml (auto-generated nightly + on publish — [../03-technical-specs/07-queues-scheduling.md](../03-technical-specs/07-queues-scheduling.md))
```
sitemap-pages.xml      (home, about, contact, legal, cities, services hubs)
sitemap-services.xml   (all service leaves, all locales)
sitemap-cities.xml
sitemap-housing.xml    (units)
sitemap-posts.xml      (blog + news, all locales)
sitemap-categories.xml (only archives with ≥ 3 posts + intro)
```
Rules: lastmod = real modified time; excludes noindex pages, search/filters, portal/admin; pinged to Search Console on major changes.

### robots.txt
```
User-agent: *
Allow: /
Disallow: /search*
Disallow: /admin* /app* /api* /preview*
Disallow: /*?tab=          # tab state is UI-only; canonical URLs are clean
Sitemap: https://sewahospitality.com/sitemap_index.xml
+ explicit AI-crawler policy (see [05-aeo-llm-presence.md](05-aeo-llm-presence.md) — we ALLOW reputable AI crawlers)
```

## 4. Structured data (one JSON-LD graph per page — generated by `Schema\Graph`)

| Page | Entities |
|---|---|
| All | `Organization` (legal name, logo, sameAs socials, contactPoint) from settings — one source of truth |
| Home | + `WebSite` (SearchAction) |
| Contact | + `LocalBusiness`/`Organization` with `address`, `geo`, `openingHours`, `telephone` per office (10-office ready) |
| Service pages | + `Service` (type, provider=@Organization, areaServed=[cities], offers range) |
| Housing/city | + `LocalBusiness` variants; housing units optionally `Accommodation` when inventory matures |
| Blog post | + `Article`/`BlogPosting` (author = named `Person` with profile + sameAs, dates, image, publisher) |
| FAQ blocks | + `FAQPage` (matches visible content only) |
| All content | + `BreadcrumbList` (visible breadcrumbs too — reference has neither) |
| Reviews | + `Review`/`AggregateRating` **only where reviews are visibly rendered with source** ([../04-modules/08-testimonials-reviews.md](../04-modules/08-testimonials-reviews.md) §3) — the reference's self-declared 9.9/1024 is banned by policy + test |

## 5. Information architecture & links
- Single H1 per page (template + CI); heading ladder guidance in editors.
- Breadcrumbs on every content page.
- **Internal linking map (money web):** service ↔ city ↔ housing ↔ posts ↔ testimonials — enforced by block pickers (e.g. city pages always list their services; service pages always list covered cities).
- Descriptive slugs, stable forever; slug changes = 301 via redirect manager with auto-suggest ([../04-modules/01-cms.md](../04-modules/01-cms.md) §4.5).
- Pagination: rel prev/next + self-canonical per page (the reference does this correctly on WP — kept).
- Tag/category archives: editable intros required when indexed; thin archives noindex,follow (rule in Blog module).
- Footer: NAP, offices, sitemap-link, socials — consistent sitewide (NAP discipline per brand doc).

## 6. Performance-as-SEO (Core Web Vitals discipline)
Budgets and mechanisms: [../05-design-system/03-ux-interactions.md](../05-design-system/03-ux-interactions.md) §4 (zero CLS by aspect boxes, ≤ 2.5s LCP via edge cache + ≤ 200KB hero, INP ≤ 200ms via islands). Third-party JS on public pages = 0 pre-consent. CI gate enforces per release ([../03-technical-specs/13-testing-qa.md](../03-technical-specs/13-testing-qa.md) gate 5).

## 7. SEO ops (ongoing)
- Daily `seo:audit` crawl ([../03-technical-specs/07-queues-scheduling.md](../03-technical-specs/07-queues-scheduling.md) §3): 200s, single H1, canonical, meta presence, accidental noindex detection → admin anomalies report.
- Search Console: verified at launch; sitemap submitted; monthly review cadence (coverage, queries, CWV) — owned by editor role, documented in [../07-marketing-trust/01-google-ecosystem.md](../07-marketing-trust/01-google-ecosystem.md).
- Redirect hygiene: hits monitored; stale redirects (> 12 months, 0 hits) reviewed yearly.
- Migration rule: any URL change ships with its 301 map in the same release — zero mass-renames.

## 8. Defect-fix traceability (reference → Sewa gate)
| Reference defect | Fix + enforcement point |
|---|---|
| No sitemap.xml/robots.txt | nightly generator + CI membership test |
| Double H1 (every post) | template rule + seo:audit + CI SEO snapshot |
| Empty `<html lang>` | locale middleware + test |
| Fake hreflang (self-referential EN-US) | real alternates generator + test |
| Placeholder metas on news | publish-gate blocks empty |
| Accidental noindex (2026 post) | explicit admin action + audit detection |
| Rating schema w/o visible reviews | schema-matches-visible rule + golden test |
| No JSON-LD on money pages | full graph per page type (§4) |
| Tag-cloud sitewide injection | per-post terms only (Blog module) |
| Broken/orphan routes | route-health CI gate |
