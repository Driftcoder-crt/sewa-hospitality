# 03 — Trust & Authority Program

**How Sewa becomes and looks like the most trusted mobility brand in India: real credentials, visible transparency, entity consistency, and the social proof engine — every trust signal the reference fakes, approximates, or neglects, done honestly.**

---

## 1. The trust gap (what the reference shows vs. proves)
The reference's footer carries 20 membership/certification logos (EuRA, ISO 27001/14001, IATA, Ministry of Tourism, FICCI…), a self-declared 9.9/10 rating from 1024 reviews, and 24 unsourced testimonials. Some are certainly real; nothing on-site proves any of them. Sewa's rule: **every visible trust signal links to its proof.**

## 2. Credentials roadmap (earned, then displayed)

| Tier | Credential | Path | Display policy |
|---|---|---|---|
| Incorporation | Company registration, PAN, GST (already held) | link proof on "About Sewa" | show with CIN once comfortable (common in India for B2B trust) |
| Industry bodies | EuRA, Worldwide ERC, IAM, CHPA membership | apply as operations mature (EuRA Relocation Quality framework is the flagship path) | badge only when membership live; links to member directory |
| Standards | ISO 27001 (data handling — corporate clients ask), ISO 9001 (quality) | phased certification projects | badge + certificate page with scope + certificate PDF |
| Regulated services | IATA (travel, if that line launches) | licensing | badge + registration number |
| Insurances | transit insurance partners (moving), professional indemnity | policies in force | a "coverage & claims" transparency note |
| Associations local | FICCI/PHD-type chamber memberships as business development warrants | per value | same rule |

**Hard rule:** the memberships block in settings starts EMPTY except what's actually held. Aspirational badges live in this doc's roadmap, never on the site. (Reference contrast: a logo wall no one can verify.)

## 4. Entity consistency (LLM/Google ground truth)
- NAP byte-identical everywhere (site settings = single source — [../01-platform-vision/02-brand-sewa-hospitality.md](../01-platform-vision/02-brand-sewa-hospitality.md) §1).
- `sameAs` maintained: LinkedIn, GBP, socials, directories (JustDial/IndiaMART-class listings for citation flow) — all claiming the same entity facts (founded year, HQ, phone).
- LinkedIn as B2B authority: company page complete (services, staff, posts); leadership active profiles linked from site — the reference's leadership page has no outbound LinkedIn links visible in the mirror.
- Wikipedia/ Crunchbase-class presence: only if independently notable later; never self-seeded (policy).

## 5. Social proof engine
1. **Review flywheel:** every completed move → request (once + one reminder) → reviews grow ([01-google-ecosystem.md](01-google-ecosystem.md) §3.2) → synced on-site with schema → service/city pages carry them.
2. **Case stories:** anonymized client scenarios by segment ("Japanese automotive supplier: 12 engineers to Pune in 6 weeks") — written from real moves with permission; the reference has zero case content.
3. **Awards/milestones:** only real recognitions; the reference has a hidden awards route with nothing public — we either earn one and show it or don't fake it.
4. **PR moments:** data-led stories (city rent-band reports from the housing module) — original data earns citations ([../06-content-seo/05-aeo-llm-presence.md](../06-content-seo/05-aeo-llm-presence.md) §2 Layer 3).

## 6. Security trust (enterprise checklist)
The platform's own posture as a selling point for corporate clients: 2FA in portal/admin, audit logs, data-retention policy, signed document links, ISO-track data practices ([../03-technical-specs/05-security-reliability.md](../03-technical-specs/05-security-reliability.md)) — summarized in plain language on the data page. (The reference's portal is an unaudited CodeIgniter login wall.)

## 7. Trust calendar (first 12 months)
| When | Action |
|---|---|
| Launch | transparency pages live, people pages, review engine armed, entity listings consistent |
| Month 1–3 | first 20 reviews, first case story, chamber/association applications in progress (roadmap page not displayed) |
| Month 4–6 | EuRA/ERC application status (if operations qualify); ISO 27001 gap assessment |
| Month 7–12 | certification milestones as achieved; 100+ reviews target; awards submissions (real ones only) |

## 8. What we never do
- Buy reviews, incentivize reviews, or gate review requests on satisfaction (the "ask only the happy" trick — it also biases the rating the wrong way long-term).
- Display unheld badges/certifications or fake statistics.
- Fake testimonials or invent "as seen in" logos.
- Overstate coverage (city services map stays truthful — [../04-modules/10-cities-content.md](../04-modules/10-cities-content.md) §5).
