# 09 — Media Pipeline

**One media system for the whole platform: Spatie Media Library conversions, required alt text, focal-point cropping, WebP/AVIF delivery, and immutable-hash URLs on media.sewahospitality.com fronted by Cloudflare.**

---

## 1. What's wrong with the reference (what we fix)

The reference: MD5-hash filenames on an API CDN, 4 fixed sizes (thumb/medium/large/original), no alt-text guarantee, eager next/image optimizer on main site but raw sizes on blog/portal, 2.5 MB PNG heroes, GIF hero banners, CSS-background galleries with no alt at all.

Sewa's media pipeline: **managed conversions, enforced alt text, modern formats, immutable caching, one delivery domain, no layout shift.**

## 2. Upload & storage model

- **Storage:** `storage/app/public/media/{namespace}/{id}/` via Spatie Media Library on the local disk (Hostinger), exposed at `media.sewahospitality.com/media/{namespace}/{id}/{file}-{conversion}.{ext}`.
- **Namespaces** (folder taxonomy): `brand/`, `services/`, `cities/`, `housing/`, `blog/`, `team/`, `csr/`, `testimonials/`, `careers/`, `portal/`, `legal/`.
- **Originals** preserved untouched; every public render uses a conversion. Originals downloadable only via signed admin URLs.
- **Uploader:** drag-drop admin uploader (Livewire `WithFileUploads`), multi-file, client-side image compress hint, progress bar; accepts jpg/png/webp (+ svg for icons/logos only, from brand namespace).
- **Limits:** images ≤ 8 MB original (server-side validated; larger rejected with guidance), PDF/DOC resume ≤ 5 MB (careers only), batch imports queued.
- **Retention:** originals kept; conversions regenerable (`media:prune` cleans orphans weekly — [07-queues-scheduling.md](07-queues-scheduling.md)).

## 3. Conversions (the responsive set)

| Conversion | Dimensions | Format | Used by |
|---|---|---|---|
| `thumb` | 150×150 crop | WebP | recent-post widgets, admin grids |
| `card` | 600×400 crop | WebP | cards, archives, housing grid |
| `hero` | 1600×900 crop | WebP + AVIF | page heroes (AVIF served where supported) |
| `wide` | 1920×1080 crop | WebP | full-bleed sections |
| `og` | 1200×630 crop | JPEG (social compatibility) | social shares — auto-selected per entity |
| `pdf-cover` | first-page render | WebP | document previews (portal) |

- **Focal point** set per media (admin focal-picker) — all crops preserve the subject across aspect ratios.
- Quality targets: WebP q=78, AVIF q=50 — visually lossless at half the reference's payloads.
- `<picture>` markup with width/height + `srcset/sizes` generated by a single Blade component (`<x-media :media="$m" conversion="card" …/>`); explicit aspect-ratio box = zero CLS.

## 4. Alt text discipline (a11y + SEO)

- `alt_text` is **required at upload** in the admin (form blocks at publish if empty — mirroring the "meta required" rule; the reference ships empty alts routinely).
- Alt guidance inline ("describe what's visible, not the file: 'Consultant handing keys to a family in Gurugram'").
- Decorative images get explicit `alt=""` via a checkbox — intentional, never accidental.
- `credit`/source field for photography attribution when needed.

## 5. Delivery domain & caching

- `media.sewahospitality.com` = static-only host: `.htaccess`/route serves conversions with `Cache-Control: public, max-age=31536000, immutable`.
- **Immutable-hash URLs:** conversion filenames include a content hash — a re-upload creates a NEW id/hash URL, so Cloudflare `Cache Everything` never serves stale pixels; no purge choreography needed.
- Cloudflare: free-tier CDN caching for media subdomain; brotli; HTTP/3; image caching lifetime 1 year.
- Monthly media transfer budgeted against Hostinger plan; Pulse records served bytes (early-warning before bandwidth throttles).

## 6. Components & usage patterns

| Component | Renders |
|---|---|
| `<x-media>` | `<picture>` with srcset/sizes/alt/width/height/lazy/loading=eager for heroes |
| `<x-gallery>` | accessible grid/carousel (scroll-snap + Alpine controls), lightbox on click (`<dialog>`, focus trap) — replaces Swiper+Fancybox |
| `<x-hero>` | hero media + overlay text + focal-aware crop (`object-position` from focal point) |
| `<x-logo>` | brand logo variants (primary/inverse/mono) from brand namespace |

Reference-beating specifics: galleries are real `<img>` tags (not CSS backgrounds), lightboxes lazy, carousels keyboard-navigable, every item has alt — see [../05-design-system/02-ui-components.md](../05-design-system/02-ui-components.md).

## 7. Pipeline jobs (queued)
- `GenerateConversions` (on upload; queued per file — admin shows progress)
- `MediaPrune` (weekly orphan sweep)
- `OptimizeOnUpload` (strip EXIF location data — privacy; keep orientation)
- `BulkImportMedia` (CSV+zip import for migration/large batches, chunked)

## 8. Privacy & compliance
- EXIF GPS stripped on ingest (EXIF privacy for clients/employees in photos).
- Person-consent flag on media (for team/client photos used in marketing; default off for portal docs).
- Portal documents (leases, visas) live under `portal/` namespace with access policies + signed URLs (never public URLs) — see [05-security-reliability.md](05-security-reliability.md).

## 9. Phase-2 options (documented, not built)
- S3-compatible object storage (Spatie supports it) when disk/bandwidth outgrows Hostinger.
- Cloudflare Images / R2 for paid-tier image optimization at scale.
- On-the-fly AVIF variants for the whole back-catalog once volume justifies CPU cost.
